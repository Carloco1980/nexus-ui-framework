# Examples

La carpeta `examples` contiene implementaciones de referencia construidas con Nexus UI Framework.

Estos ejemplos tienen como objetivo demostrar el uso del Framework en distintos escenarios, sin formar parte del núcleo (Core).

## Objetivos

- Mostrar buenas prácticas de implementación.
- Servir como guía para desarrolladores.
- Validar el funcionamiento de componentes reutilizables.
- Probar nuevas funcionalidades antes de incorporarlas al Core.

## Estructura

```text
examples/
└── landing/
```

Cada ejemplo debe ser independiente y utilizar únicamente los recursos públicos del Framework.
