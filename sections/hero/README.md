# Hero

## Descripción

Sección de presentación para comunicar la propuesta principal de una página.

## Uso

Consulta `hero.html` para el marcado de ejemplo y `hero.css` para las variantes de fondo, contenido y distribución. Ajusta el nivel del encabezado a la jerarquía de la página que lo consuma.

## Responsive y accesibilidad

El contenido se apila en pantallas estrechas. Proporciona texto alternativo a los medios informativos y conserva contraste suficiente sobre fondos de imagen o video.
