Navigation

Navbar

Barra principal responsive. La instancia funcional de esta página está en el encabezado.

Ir a la Navbar activa

HTML

<header class="nx-header">
  <div class="nx-container">
    <nav class="nx-navbar" aria-label="Navegación principal">
      <a class="nx-navbar-brand" href="#inicio">Nexus</a>
      <ul id="nx-navbar-menu" class="nx-navbar-menu">...</ul>
      <button id="nx-mobile-button" class="nx-mobile-button"
        type="button" aria-controls="nx-navbar-menu"
        aria-expanded="false" aria-label="Abrir menú">...</button>
    </nav>
  </div>
</header>

Clases: nx-header, nx-navbar, nx-navbar-brand, nx-navbar-menu, nx-navbar-actions, nx-mobile-button.

API: NX.navbar.init(), toggleMenu(), closeMenu(). Los IDs del menú y botón móvil son selectores de la API del módulo.

Accesibilidad: nombra el landmark nav y conserva aria-controls y aria-expanded.

Theme

Theme Toggle

El botón del encabezado alterna el tema mediante el servicio público de Theme.

Ir al control de tema activo

HTML

<button id="nx-theme-button" class="nx-theme-toggle"
  type="button" aria-label="Cambiar tema" aria-pressed="false">
  <span class="nx-theme-toggle__thumb" aria-hidden="true"></span>
</button>

Clases: nx-theme-toggle, nx-theme-toggle__thumb.

API: NX.theme.set(), get(), current(), toggle(), reset(). Evento: nx:themechange.

Accesibilidad: aria-pressed refleja el tema actual. Los tokens se seleccionan con data-nx-theme en el elemento raíz.

Animations

El módulo revela elementos marcados con data-nx-animation al entrar en el viewport.

Fade up

Animación de entrada del módulo.

HTML

<article class="nx-card" data-nx-animation="fade-up">
  <div class="nx-card-body">Contenido</div>
</article>

Atributos: fade-up, fade-down, fade-left, fade-right, zoom.

API: NX.animations.init(); configuración en NX.config.animations.

Accesibilidad: el contenido debe seguir comprensible con movimiento reducido o sin animación.

API pública

Inicialización y eventos

Los módulos incluidos en la página se registran en window.NX y el bootstrap los inicializa automáticamente.

Servicios principales

Theme: NX.theme.set(), get(), current(), toggle(), reset(); evento nx:themechange.

Modal: NX.modal.open(id), close(id), toggle(id); eventos modal:open y modal:close.

Icons: NX.icons.refresh(), load(name), clearCache().

Configuración: NX.config contiene las opciones de tema, navbar, modal, iconos, animaciones, breakpoints y debug.
