# Roadmap

Este documento describe la evolución planificada de **Nexus UI Framework**.

El desarrollo del Framework seguirá un enfoque incremental, donde cada versión deberá ser estable, reutilizable, documentada y compatible con la arquitectura existente.

---

# Estado Actual

**Versión actual**

```
0.9.0 RC1
```

Estado:

> Release Candidate

Se ha completado la arquitectura base del Framework y comienza la etapa de consolidación previa a la versión estable 1.0.

---

# Principios de Evolución

Antes de comenzar una nueva versión se debe verificar que:

- El Core permanece estable.
- La documentación está actualizada.
- No existen componentes duplicados.
- Se mantiene el principio de "una responsabilidad por archivo".
- Se respetan los Design Tokens.
- Todos los componentes son responsive.
- Se mantiene la compatibilidad con versiones anteriores siempre que sea posible.

# Criterios para una Nueva Versión

Una versión solo podrá publicarse cuando:

- Todos los componentes estén documentados.
- Se hayan realizado pruebas funcionales.
- No existan errores críticos.
- El CHANGELOG esté actualizado.
- El README refleje las nuevas funcionalidades.
- La arquitectura permanezca consistente.
