# Hoja de ruta

Esta hoja de ruta describe trabajo candidato, no funcionalidades incluidas en la versión 1.0.0. Las propuestas pueden cambiar tras su revisión; no implican fechas ni compromisos de entrega.

## v1.1 — exploración planificada

La hoja de ruta existente identifica estas áreas para evaluación:

- Tabs
- Accordion
- Dropdown
- Toast y notificaciones

Antes de implementarlas, se evaluarán según las necesidades de uso, accesibilidad, API de componentes existente y costo de mantenimiento. Esta lista no representa funcionalidades disponibles.

## Consideraciones posteriores

Ideas registradas anteriormente para versiones futuras incluyen DataTable, Calendar, Timeline y soporte para gráficos. No son compromisos y no forman parte de la versión 1.0.0.
