# Catalog

## Descripción

Módulo JavaScript que lee el registry y construye tarjetas de catálogo en el contenedor de la página.

## Uso

Incluye `catalog.css` y `catalog.js`. La página debe proporcionar `#component-catalog`; los filtros usan `#category-filter` y `#catalog-status`.

## Archivos

- `catalog.css`
- `catalog.js`
- Registry: `../registry/components.json`

## Dependencias

Requiere el registry JSON y la estructura de catálogo descrita arriba.
