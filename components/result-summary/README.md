# Result Summary

Reusable result count pattern for filtered lists and catalogs.

```html
<section class="nx-result-summary" aria-label="Resumen de resultados">
    <span class="nx-result-summary__badge nx-badge nx-badge-info"><span class="nx-badge-dot" aria-hidden="true"></span> RESULTADOS</span>
    <div class="nx-result-summary__content" aria-live="polite" aria-atomic="true">
        <p class="nx-result-summary__value">79</p>
        <p class="nx-result-summary__label">Iniciativas encontradas</p>
    </div>
    <p class="nx-result-summary__description">Mostrando los resultados que cumplen los filtros seleccionados.</p>
</section>
```

The component uses Nexus tokens and adapts its compact composition at tablet and mobile breakpoints.
