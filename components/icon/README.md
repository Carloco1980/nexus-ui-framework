# Icon

## Descripción

Módulo que inserta los iconos SVG disponibles en `assets/icons/` en elementos marcados con `data-nx-icon`.

## Uso

Incluye `icon.css` y `icon.js`. Los nombres de icono disponibles se limitan a los SVG presentes en `assets/icons/`.

## Accesibilidad

Marca como decorativos los iconos redundantes y proporciona un nombre accesible si comunican información.

## Estado

Estable.
