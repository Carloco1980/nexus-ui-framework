# Chart Card

## Descripción

Panel de presentación para gráficos, métricas y contenido relacionado. No incluye una biblioteca de gráficos.

## Uso

Consulta `chart-card.html` para el marcado y `chart-card.css` para sus estilos. La aplicación debe proporcionar y describir los datos del gráfico.

## Clases

- `nx-chart-card`
- `nx-chart-body`
- `nx-chart-divider`
- `nx-chart-metrics`

## Dependencias

Se compone con los estilos de Panel.

## Estado

Estable.
