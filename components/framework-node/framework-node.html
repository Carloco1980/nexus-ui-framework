Services

Conjunto de servicios reutilizables que proporcionan funcionalidades comunes para cualquier aplicación construida con Nexus Ecosystem.

Core

Nexus Core

Define contratos, configuración, eventos, autenticación y la experiencia compartida entre todos los módulos del ecosistema.

Repository

Centraliza el acceso a los datos y abstrae las diferentes fuentes de información del ecosistema.

Adapters

Integraciones con WordPress, Google Drive, SharePoint, Amazon S3, LDAP, OAuth y otros servicios externos.

AI Services

Servicios inteligentes para búsqueda, automatización, asistentes y análisis de información.
