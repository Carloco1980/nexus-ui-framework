# Feature Card

Feature Card is a reusable card component used to highlight
framework capabilities.

## Usage

```html
<article class="nx-card nx-feature-card">

    <div class="nx-feature-icon">
        🚀
    </div>

    <h3>Modern Components</h3>

    <p>
        Build dashboards with reusable UI components.
    </p>

</article>
