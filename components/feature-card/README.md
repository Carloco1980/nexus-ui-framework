# Feature Card

Tarjeta reutilizable para destacar una característica o beneficio del producto.

## Uso

```html
<article class="nx-card nx-feature-card">

    <div class="nx-feature-icon" aria-hidden="true">
        <span class="nx-icon">✦</span>
    </div>

    <h3>Componentes modernos</h3>

    <p>
        Construye interfaces con componentes reutilizables.
    </p>

</article>
```

## Archivos

Consulta `feature-card.html` para el ejemplo de marcado. Los estilos se comparten con Card y la sección Features.

## Accesibilidad

Usa un encabezado con nivel coherente con la página y conserva texto suficiente para explicar la característica.
