# Floating Action Button

## Descripción

Botón visual para una acción principal. El módulo JavaScript inicializa enlaces de WhatsApp configurados mediante atributos `data-*`.

## Uso

Para un enlace de WhatsApp, aplica `.nx-fab` y `.nx-whatsapp-button` a un `<a>`, y añade `data-whatsapp-number` con el prefijo internacional, sin `+`. Consulta `fab.html` para la vista previa estática, `fab.css` para estilos y `fab.js` para el comportamiento disponible.

## Accesibilidad

El botón debe tener un nombre accesible que describa su acción.
