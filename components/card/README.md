# Card

## Descripción

Componente contenedor reutilizable para mostrar información, estadísticas, contenido o acciones.

## Uso

```html
<article class="nx-card">

    <div class="nx-card-body">

        <span class="nx-badge">
            Dashboard
        </span>

        <h3 class="nx-card-title">
            Título
        </h3>

        <p class="nx-card-text">
            Descripción.
        </p>

    </div>

</article>
```

- Button
