# Theme Toggle

## Descripción

Control y módulo para cambiar el tema del framework. La carpeta conserva su nombre físico actual.

## Uso

Incluye `theme-toggle.css` y `theme-toggle.js`. El módulo utiliza el servicio de tema del core y sincroniza todos los controles con la clase `.nx-theme-toggle`; el identificador `#nx-theme-button` es opcional para la integración de cada aplicación.

## Accesibilidad

Usa un nombre accesible y sincroniza `aria-pressed` con el estado que representa el control.

## Estado

Estable.
