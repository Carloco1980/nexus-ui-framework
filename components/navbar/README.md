# Navbar

## Descripción

Barra de navegación responsive con controles de menú para pantallas estrechas.

## Uso

Consulta `navbar.html` para el marcado, `navbar.css` para estilos y `navbar.js` para la interacción.

## Accesibilidad

Nombra el landmark de navegación y sincroniza `aria-expanded` con el estado del menú.

## Estado

Estable.
