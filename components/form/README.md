# Form

## Descripción

Estilos y módulo de envío para formularios del framework.

## Uso

Consulta `form.html` para el marcado, `form.css` para estilos y `form.js` para el módulo JavaScript. El envío requiere configurar un destino compatible.

## Accesibilidad

Asocia cada etiqueta con su control y presenta los mensajes de estado a las tecnologías de asistencia.

## Estado

Estable.
