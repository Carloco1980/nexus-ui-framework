# Modal

## Descripción

Ventana modal con estilos y módulo JavaScript para su interacción.

## Uso

Consulta `modal.html` para el marcado, `modal.css` para estilos y `modal.js` para la API disponible.

## Accesibilidad

Asocia el diálogo con su título y conserva controles accesibles para abrirlo y cerrarlo.

## Estado

Estable.
