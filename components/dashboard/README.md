# Dashboard

## Descripción

Layout para organizar encabezado, indicadores KPI y paneles en una vista de resumen.

## Uso

Consulta `dashboard.html` para el ejemplo y `dashboard.css` para los estilos.

## Clases

- `nx-dashboard`
- `nx-dashboard-header`
- `nx-dashboard-kpis`
- `nx-dashboard-charts`

## Dependencias

Puede componerse con Panel, KPI y Chart Card.

## Estado

Estable.
