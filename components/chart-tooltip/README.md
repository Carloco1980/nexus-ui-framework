# Chart Tooltip

Nexus-styled shared tooltip for Chart.js 4. Load `assets/js/components/chart-tooltip.js` after Chart.js and before chart creation. The installer sets the shared Chart.js tooltip defaults; every chart inherits the same accessible card, theme tokens, series marker, and label/value layout.

Include `components/chart-tooltip/chart-tooltip.css` in the framework CSS bundle. Do not add per-chart tooltip styling or callbacks.
