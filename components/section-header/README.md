# Section Header

## Descripción

Componente reutilizable para encabezados de sección.

## Uso

```html
<div class="nx-section-header">

    <span class="nx-badge">
        Dashboard
    </span>

    <h2 class="nx-section-title">
        Título
    </h2>

    <p class="nx-section-description">
        Descripción.
    </p>

</div>
```

## Clases utilizadas

- nx-section-header
- nx-badge
- nx-section-title
- nx-section-description

## Dependencias

Ninguna.

## Estado

Estable.
