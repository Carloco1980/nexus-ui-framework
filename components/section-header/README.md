# Section Header

## Descripción

Estilos para encabezados que presentan y contextualizan una sección.

## Uso

Incluye `section-header.css` y elige el nivel de encabezado de acuerdo con la jerarquía del documento.

## Clases

- `nx-section-header`
- `nx-section-header-left`
- `nx-section-header-center`
- `nx-section-header-right`
