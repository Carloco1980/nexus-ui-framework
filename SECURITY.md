# Política de seguridad

## Versión

Los reportes deben indicar la versión o el commit afectado. La versión estable actual es 1.0.0. Este documento no establece un periodo de soporte para versiones anteriores.

## Reportar una vulnerabilidad

Reporta posibles vulnerabilidades de forma privada mediante la función **Report a vulnerability** de GitHub en el repositorio de Nexus UI Framework:

https://github.com/Carloco1980/nexus-ui-framework/security/advisories/new

No publiques detalles de explotación en issues o pull requests antes de que las personas mantenedoras puedan evaluar el reporte. Incluye la versión o los archivos afectados, el impacto, pasos para reproducirlo y una mitigación sugerida si la tienes. Evita enviar datos personales o información sensible no relacionada.

Las personas mantenedoras acusarán recibo y evaluarán los reportes según su disponibilidad. No se garantiza un plazo de respuesta o corrección. Da tiempo para la evaluación y la divulgación coordinada antes de hacer público un problema sin corregir.
