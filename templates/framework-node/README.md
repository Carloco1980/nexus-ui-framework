# Nexus UI Framework

<p align="center">

Modern UI Framework for Dashboards, Landing Pages, Enterprise Applications and WordPress.

Designed for speed, consistency and beautiful interfaces.

</p>

---

## Overview

Nexus UI Framework es un framework CSS moderno construido para crear interfaces elegantes utilizando un único sistema de diseño.

Su objetivo es ofrecer componentes reutilizables, un Design System consistente y una arquitectura modular que pueda utilizarse en:

- Dashboards
- Landing Pages
- WordPress
- Plugins
- Aplicaciones Web
- Sistemas Empresariales

---

## Philosophy

Nexus UI sigue cuatro principios fundamentales.

- Design Tokens First
- Reusable Components
- Modern CSS
- Framework Agnostic

No depende de React, Vue, Angular o Bootstrap.

Puede integrarse en cualquier proyecto HTML.

# Installation

Clone repository

```bash
git clone https://github.com/...
```

Install

```bash
npm install
```

Development

```bash
npm run dev
```

Build

```bash
npm run build
```

---

# Quick Start

Import the framework

```html
<link rel="stylesheet" href="dist/nexus-ui.css">
```

Example

```html
<button class="nx-btn nx-btn-primary">
Get Started
</button>
```

# Design Tokens

Everything is driven by CSS Variables.

Example

```css
--nx-primary
--nx-green
--nx-cyan

--nx-space-md

--nx-radius-md

--nx-shadow-md

--nx-transition
```
