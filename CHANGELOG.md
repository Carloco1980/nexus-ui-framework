# Registro de cambios

Aquí se documentan los cambios importantes de Nexus UI Framework. Las versiones siguen Semantic Versioning.

## [1.0.0] - 2026-10

Primera versión estable.

- Establece el namespace `window.NX` y el Core JavaScript compartido para inicialización, configuración, eventos, almacenamiento, temas y animaciones.
- Incluye temas claro y oscuro y design tokens CSS compartidos.
- Incluye los componentes registrados y las secciones de página disponibles bajo `sections/`.
- Genera las hojas CSS `dist/nexus-ui.css` y `dist/nexus-ui-components.css`.

Consulta [`components/registry/components.json`](components/registry/components.json) para ver el catálogo actual y el estado de cada componente.
