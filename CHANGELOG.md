# Changelog

Todos los cambios importantes del proyecto **Nexus UI Framework** serán documentados en este archivo.

El formato está inspirado en **Keep a Changelog** y el proyecto utiliza Versionado Semántico (Semantic Versioning).

---

## [0.9.0 RC1] - 2026-09

### 🎉 Primera Release Candidate

Esta versión representa la primera base estable del **Nexus UI Framework**, estableciendo la arquitectura modular del proyecto.

## Mejorado

- Organización completa de carpetas.
- Separación entre Base, Layout, Components, Sections y Utilities.
- Modularización completa del JavaScript.
- Preparado para crecimiento mediante módulos independientes.

---

## Arquitectura

Se adopta oficialmente el principio:

> **Un archivo = una responsabilidad.**

El núcleo del Framework únicamente inicializa módulos.

Cada componente mantiene su propia lógica.

---

## Compatibilidad

Probado en navegadores modernos compatibles con:

- CSS Variables
- CSS Grid
- Flexbox
- ES6+
- IntersectionObserver
